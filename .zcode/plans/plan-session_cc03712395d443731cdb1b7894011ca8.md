# DevOpsHelper 运维学习与面试备战平台 — 设计与开发计划

一个单用户本地学习工具：**分类面试题库 + Docker 沙箱实操 + 个人知识库 + 间隔复习 + 可选 AI 辅助**。技术栈：Spring Boot 3 + Vue3 前后端分离 + MySQL + Docker。项目本身附带 Dockerfile/docker-compose，日后可直接部署到学生云服务器，成为第一个 DevOps 实战作品。

## 一、整体架构

```
浏览器 (Vue3 + Element Plus + xterm.js + ECharts)
   │ REST + WebSocket
后端 Spring Boot 3 (JDK 17)
   ├─ 题库/知识库/复习计划 API
   ├─ Lab 沙箱管理 (docker-java: 容器生命周期/Web终端桥接/判分)
   └─ AI 模块 (可选, OpenAI 兼容 API, 流式 SSE)
   │                │
 MySQL 8         Docker Engine (Lab 沙箱容器)
(题库/进度/笔记)   (每个实操题一个真实 Linux 容器, 预埋故障)
```

不做用户登录（单用户本地工具，表里预留 user_id 字段便于扩展）。

## 二、功能模块

**1. 面试题库**：题目按「知识点树 × 难度 × 岗位」组织。题型：问答（含参考答案+追问）、场景排障（文字版）、选择。刷题模式：按知识点专项/随机/错题重刷；答完自评（会/模糊/不会）进复习队列。
知识点树（8 大类）：Linux、网络排障、Shell/脚本、Nginx、Docker、Kubernetes、CI/CD、监控日志；外加 MySQL/Redis/MQ 中间件运维。岗位：初级运维、DevOps 工程师、SRE、云计算工程师（每个岗位一张技能路线图+推荐题集，进度可视化）。

**2. 实操实验室 Lab（核心亮点）**：每个 Lab = 镜像 + 预埋故障脚本 setup + 场景描述 + 分级提示 + 检测脚本 check + 参考答案。流程：选 Lab → 后台启动容器（限时 60 分钟、CPU/内存限额、用完自动销毁）→ 浏览器 xterm.js 连 WebSocket 进真实终端 → 排查修复 → 点「检测」→ 后台 docker exec 跑 check 脚本返回逐项结果 → 销毁。首版 10 个 Lab：磁盘写满排查、CPU 打满进程处理、文件权限修复、端口不通排查、Nginx 起不来（配置错误）、SSH 登录失败、应用 OOM 排查、容器反复重启排查、日志分析脚本、MySQL 连不上排查。自建基础镜像 `devopshelper-base`（ubuntu:22.04 + 预装 nginx/mysql-client/常用排查工具）。注：容器内无 systemd，场景用进程方式模拟。

**3. 知识库**：Markdown 文章按知识点树组织，编辑器 + 预览（md-editor-v3）；与题目双向关联；每题可加个人笔记。

**4. 复习系统**：SM-2 间隔重复算法（同 Anki）：不会→1 天、模糊→3 天、会→按间隔倍增；每日复习队列；仪表盘 ECharts 展示知识点掌握度雷达图、刷题曲线、Lab 完成数。

**5. AI 辅助（可选开关）**：设置页配置 OpenAI 兼容 base-url/api-key/model（兼容 GLM/DeepSeek）。功能：按岗位+知识点生成新题、对某题追问、模拟面试官多轮提问、给用户答案评分。未配置则全部隐藏，不影响核心功能。

## 三、核心数据表

position(岗位)、topic(知识点树)、question(题目：type/difficulty/title/answer/hints/tags/frequency)、lab(实验定义)、lab_instance(容器实例：container_id/status/started_at/expired_at)、review_record(SM-2：quality/ease_factor/interval_days/next_review_at)、note(笔记，关联 question/lab/topic)、kb_article(知识库文章)、ai_config。Lab 定义用 YAML 文件存在 `labs/definitions/`，启动时导入。

## 四、项目结构

```
devopsHepler/
├── backend/   Spring Boot: config/ controller/ service/ mapper/ entity/
│              lab/(LabContainerManager, TerminalWebSocketHandler, CheckExecutor)
│              ai/ review/(SM-2)  resources/db/migration/(Flyway建表+种子题库)
├── frontend/  Vue3+Vite+JS: views/(Dashboard,Questions,Review,Labs,LabDetail终端,
│              Knowledge,Positions,Settings) api/ stores/ router/
├── labs/      images/devopshelper-base/Dockerfile + definitions/*.yml (10个Lab)
├── docker-compose.yml  backend/Dockerfile  frontend/Dockerfile(nginx)  README.md
```

技术细节：MyBatis-Plus（国内岗位主流）、Flyway（建表+数据初始化，本身是 DevOps 知识点）、docker-java 管理容器与 exec、WebSocket+xterm.js(tty 模式+尺寸同步)、前端 JavaScript（不用 TS，降低门槛）。

## 五、内置内容规模（首版）

约 100 道精选问答/场景题（每知识点 10~15 道高频）+ 10 个实操 Lab + 10 篇知识库骨架文章 + 4 个岗位路线图。内容由我编写，随 Flyway 种子数据/资源文件交付。

## 六、开发里程碑（每个结束都是可用状态）

- **M1 骨架+题库核心**：环境检查脚本 → 后端脚手架+MySQL+Flyway → 题库 API+种子数据 → 前端脚手架 → 刷题/筛选/自评/错题本页面。
- **M2 知识库+复习**：Markdown 知识库+笔记 → SM-2 复习队列 → 仪表盘图表。
- **M3 Lab 沙箱**：docker-java 容器管理 → WebSocket Web 终端 → Lab 定义解析+预埋+判分引擎 → 基础镜像 + 10 个 Lab。
- **M4 AI+部署**：AI 配置与流式生成/模拟面试 → 岗位路线图 → 双 Dockerfile+docker-compose+README 部署文档 → git 初始化提交。

## 七、前置环境要求（M1 起需 JDK17+/Maven/Node18+/MySQL8，M3 起需 Docker Desktop）

第一步先跑环境检查脚本，缺什么装什么，再开始 M1。

## 八、主要风险与对策

Docker Desktop 依赖 WSL2（Win 首次配置可能踩坑，README 写清）；docker-java API 较繁（统一封装在 LabContainerManager）；容器内无 systemd（场景设计避开，用进程模拟）；终端中文编码强制 UTF-8。
